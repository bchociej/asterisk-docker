Alpine's Asterisk compatibility patches, unmodified, from:
https://github.com/alpinelinux/aports/tree/35f5eb2864e50dd4448758d31f3e2a32f733ab84/main/asterisk

These address musl compatibility, not Asterisk security updates. Asterisk itself
is pinned to a newer upstream release in the Dockerfile. Upstream notices in
individual patches are retained.
